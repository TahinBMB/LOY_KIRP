# LOY_KIRP

Bioinformatics analysis of mosaic loss of chromosome Y (LOY) in TCGA Kidney Renal Papillary Cell Carcinoma (KIRP).

## Analyses Included

- LOY detection
- Differential gene expression
- Functional enrichment (GO, KEGG, GSEA)
- DNA methylation analysis
- Immune infiltration analysis
- Single-cell RNA-seq analysis
- External cohort validation
- Survival analysis

## Software

- R
- Bioconductor
- DESeq2
- limma
- clusterProfiler
- Seurat
- GSVA
- xCell
- cibersortX
- Estimate
